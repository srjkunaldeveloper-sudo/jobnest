# JobNest Enterprise

**JobNest Enterprise Recruiter Suite & Applicant Tracking System (ATS)** is a modern, enterprise-grade recruitment platform built with Flutter. Designed for recruiters, hiring managers, and HR teams, JobNest delivers a seamless, high-performance user experience across mobile, tablet, and desktop interfaces.

## 🌟 Overview & Key Capabilities

- **Authentication & Security Suite**: Enterprise onboarding, login, OTP verification, password recovery, and multi-factor authentication (2FA) UI workflows with session management.
- **Home Dashboard & Analytics**: Real-time recruitment metrics, hiring pipeline probability, daily tasks, recent activity timeline, AI assistant shortcut, and smart notifications.
- **Job Requisition Management (ATS)**: Complete job creation wizard with AI-powered description generation, multi-stage applicant pipelines, candidate ranking, and requisition filtering.
- **Candidate Pipeline & CRM**: Comprehensive candidate profiles, AI skill matching scores, timeline logs, interview feedback, communication history, and document previewing.
- **Recruiter Services Hub**: Integrated tools for HRMS attendance, CRM client management, employee performance dashboards, workflow automation, and custom BI reporting.
- **Profile & Enterprise Settings**: Synchronized recruiter profile, organization credentials, billing & subscription management, accessibility options, and 24/7 priority support center.

## 🛠️ Architecture & Technology Stack

- **Framework**: Flutter 3 / Dart (Material 3 Design Language)
- **State Management**: Provider (Synchronized single-source-of-truth repositories for Jobs, Candidates, Notifications, and Profile)
- **Persistence**: SharedPreferences for local preferences and session state
- **Responsive Geometry**: Elastic layouts supporting 320px, 360px, 390px, 412px, 768px, and 1024px targets with zero layout overflow
- **Accessibility**: 48x48 dp minimum touch targets, semantic screen reader annotations, and WCAG-compliant contrast
